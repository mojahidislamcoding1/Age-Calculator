# Age Calculator

A simple age calculator built with HTML, CSS, and vanilla JavaScript. Select a birth date and a current date, click Calculate, and your exact age is shown in a modal.

## Features

- Select dates using the browser's calendar input
- Calculates age in years, months, and days
- Result shown in a modal popup
- Validates empty fields and wrong date order

## Built With

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository
2. Open `index.html` in your browser

## How It Works

The date input returns a value like `2003-05-14`. The script splits it into year, month, and day, then subtracts the birth date from the current date. If days or months become negative, it borrows from the previous month or year.
